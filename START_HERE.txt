¿QUÉ ES?
═══════════════════════════════════════════════════════════════════════

Aquadecomp descompila aplicaciones Android usando múltiples
herramientas en cadena:

MOTORES:
  1. JADX        (motor principal, produce el código Java)
  2. CFR         (rescata clases que JADX no genera)
  3. Procyon     (segundo motor de rescate)
  4. Vineflower  (tercer motor de rescate)

Los motores de rescate trabajan sobre el APK convertido a JAR con
dex2jar y solo procesan las clases que faltan en output/sources/.

MOTORES DE RECUPERACIÓN (experimental, v0.3):
  • StringDecryptionEngine    - Recupera strings encriptados
  • NameRecoveryEngine        - Recupera nombres desde ProGuard/Kotlin
  • DeobfuscationEngine       - Desofuscación automática
  • ClassRecoveryEngine       - Recupera clases perdidas
  • MetadataExtractor         - Preserva metadata
  • RealCompilationVerifier   - Verifica con javac REAL

ESTADO: Los motores de recuperación todavía no forman parte del
flujo principal de descompilación.


CÓMO USAR
═══════════════════════════════════════════════════════════════════════

PASO 1: Abre terminal y ve al directorio del proyecto
  cd "c:\Users\memit\Documents\Default Project\Aquadecomp"

PASO 2: Descompila tu APK
  java -jar build/libs/aquedecomp.jar decompile tu_app.apk -o ./output

PASO 3: Espera a que termine
  - Apps pequeñas (5 MB):     ~5-10 segundos
  - Apps medianas (50 MB):    ~30-60 segundos  
  - Apps grandes (150 MB):    ~2-3 minutos

PASO 4: Abre los reportes generados
  - output/aquedecomp-report.md (lectura fácil)
  - output/aquedecomp-report.json (máquina readable)
  - output/sources/ (código decompilado)
  - output/resources/ (imágenes, layouts, etc)

PUNTUACIÓN DE CONFIANZA (experimental)
═══════════════════════════════════════════════════════════════════════

El paquete verification puntúa cada clase 0-100 (aún no forma parte
del flujo principal; el flujo principal reporta efectividad global):

   90-100: Excelente (perfecto, seguro usar)
   75-89: Bueno (muy bueno, confiable)
   60-74: Aceptable (útil como referencia)
   40-59: Pobre (problemático)
   25-39: No confiable (NO usar)
   0-24: Solo Smali (bytecode puro)

LO ESPECIAL DE AQUADECOMP
═══════════════════════════════════════════════════════════════════════

1. CADENA MULTI-MOTOR
   JADX descompila; las clases que falten las rescatan
   CFR, Procyon y Vineflower vía dex2jar
   Resultado: más clases que con JADX solo

2. PUNTUACIÓN POR CLASE
   No solo descompila, sino que te dice qué confiar
   Score 0-100 + 6 niveles de confianza

3. REPORTES COMPLETOS
   JSON para máquinas, Markdown para humanos
   Estadísticas de compilabilidad y distribución

4. MODULAR
   Agregar nuevos descompiladores es trivial
   Interfaz DecompilerStrategy

EJEMPLO DE REPORTE
═══════════════════════════════════════════════════════════════════════

Después de descompilación, verás algo como:

  EFECTIVIDAD GLOBAL:  78.5 / 100
  Cobertura      :  94.7  44100/46528 clases
  Integridad     :  88.0  12 errores
  Identificadores:  62.0  ofuscación MEDIA
  Recursos       :  95.0  OK

Significado:
- Efectividad > 80 = BUENO (código aprovechable)
- Efectividad < 50 = PROTEGIDO (probablemente empacado)
- Identificadores bajos = nombres ofuscados (sin mapping.txt no se recuperan)


FLUJO TÍPICO
═══════════════════════════════════════════════════════════════════════

1. Ejecuta descompilación
   java -jar aquedecomp.jar decompile target.apk -o ./analysis

2. Lee el reporte
   cat ./analysis/aquedecomp-report.md

3. Interpreta resultados
   - Efectividad alta (> 80) = Código limpio
   - Efectividad baja (< 50) = Probablemente protegido
   - Señales de ofuscación en el reporte

4. Explora el código
   Abre ./analysis/sources/ en tu IDE favorito

5. Analiza resultados
   Usa las dimensiones del puntaje para filtrar por confiabilidad


PROBLEMAS COMUNES
═══════════════════════════════════════════════════════════════════════

P: "OutOfMemoryError"
R: Aumenta memoria: java -Xmx12g -jar aquedecomp.jar ...

P: "Proceso muy lento"
R: Usa más threads: ... --threads 16

P: "Score muy bajo"
R: Leer reporte - probablemente protegido
   Verifica aquedecomp-report.md para detalles

P: "¿Qué significa score bajo?"
