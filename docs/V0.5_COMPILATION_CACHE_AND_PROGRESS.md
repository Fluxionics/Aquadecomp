## Major Features

### 1. Compilation Result Caching

**Problem**: Identical files compiled repeatedly = wasted CPU/time
**Solution**: SHA-256 hash-based caching of compilation results

```java
CompilationCache cache = new CompilationCache(true);  // Enabled
RealCompilationVerifier.CompilationResult result = cache.get(javaFile);
if (result == null) {
    result = verifier.verify(javaFile);
    cache.put(javaFile, result);
}
```

**Benefits**:
- **Incremental Builds**: Second run 10-50x faster
- **CI/CD Pipelines**: Cache between builds
- **Development**: Quick reprocessing of large apps
- **Memory**: Concurrent hash map, lock-free

#### How It Works

1. **File Hashing**: SHA-256 of complete file content
2. **Lookup**: O(1) ConcurrentHashMap lookup
3. **Cache Hit**: Return cached result (~1ms vs ~100ms javac)
4. **Cache Miss**: Compile and cache result
5. **Statistics**: Track hit/miss rate

```
First run:  500 files → 500 compilations → 208 seconds
Second run: 500 files → ~50 compilations → 4 seconds (if ~90% unchanged)
```

#### API

```java
// Create with caching enabled (default)
CompilationCache cache = new CompilationCache();

// Create disabled (for testing)
CompilationCache cache = new CompilationCache(false);

// Check cache before verifying
CompilationResult result = cache.get(javaFile);

// Store result in cache
cache.put(javaFile, compilationResult);

// Get statistics
CompilationCache.CacheStats stats = cache.getStats();
System.out.println(stats.summary());
// Output: "Cache: 450 hits, 50 misses (90.0% hit rate), 500 cached results"

// Clear cache
cache.clear();
```

#### Cache Statistics

```java
CacheStats stats = cache.getStats();
stats.hits()      // 450 (successful lookups)
stats.misses()    // 50 (compilation needed)
stats.cacheSize() // 500 (total entries)
stats.hitRate()   // 90.0 (percentage)
stats.summary()   // Human-readable string
```

### 2. Progress Monitoring & Callbacks

**Problem**: Long recovery runs without feedback = user frustration
**Solution**: Event-based progress listener interface

```java
ParallelRecoveryPipeline pipeline = new ParallelRecoveryPipeline(8);

pipeline.addProgressListener(new RecoveryProgressListener() {
    @Override
    public void onRecoveryStart(int totalFiles, int threadCount) {
        System.out.println("Starting recovery: " + totalFiles + " files, " + 
                           threadCount + " threads");
    }
    
    @Override
    public void onFileComplete(Path file, int fileNumber, int totalFiles, 
                               RecoveryResult result) {
        System.out.printf("[%d/%d] %s: score=%d, time=%dms%n",
            fileNumber, totalFiles, file.getFileName(),
            result.compilationScore(), result.processingTimeMs());
    }
    
    @Override
    public void onRecoveryComplete(int totalFiles, int filesRecovered, 
                                   double recoveryRate) {
        System.out.printf("Recovery complete: %d/%d files (%.1f%%)%n",
            filesRecovered, totalFiles, recoveryRate);
    }
});

pipeline.recover(sourcesDir, resourcesDir);
```

#### Events Available

| Event | Timing | Parameters | Use Case |
|-------|--------|-----------|----------|
| `onRecoveryStart` | Before processing | Total files, thread count | Display start message |
| `onFileStart` | Before each file | File path, file #, total | Progress bar position |
| `onStringDecryptionComplete` | After string recovery | File, strings recovered | Detail tracking |
| `onNameRecoveryComplete` | After name recovery | File, names recovered | Detail tracking |
| `onDeobfuscationComplete` | After deobfuscation | File, variables recovered | Detail tracking |
| `onClassRecoveryComplete` | After class recovery | File, classes recovered | Detail tracking |
| `onCompilationComplete` | After javac | File, score, success | Validation feedback |
| `onFileComplete` | After file done | File, file #, total, result | Overall progress |
| `onRecoveryComplete` | After all files | Total files, recovered, rate | Final statistics |
| `onError` | On exception | File, error message | Error handling |

#### Adapter Pattern

For cases donde solo necesitas algunos eventos:

```java
class MyProgressListener extends RecoveryProgressListener.RecoveryProgressAdapter {
    @Override
    public void onFileComplete(Path file, int fileNumber, int totalFiles,
                               RecoveryResult result) {
        int percentage = (fileNumber * 100) / totalFiles;
        System.out.printf("[%3d%%] %s%n", percentage, file.getFileName());
    }
}

pipeline.addProgressListener(new MyProgressListener());
```

## Implementation Details

### CompilationCache

```java
public final class CompilationCache {
    private final ConcurrentHashMap<String, CacheEntry> cache;
    private final boolean enabled;
    private long totalHits;
    private long totalMisses;
    
    public CompilationCache()                  // enabled, default
    public CompilationCache(boolean enabled)   // explicit enable/disable
    
    public get(Path javaFile)                  // Lookup by file hash
    public put(Path javaFile, result)          // Store result
    public clear()                             // Reset cache
    public getStats()                          // CacheStats
}
```

#### Hashing Strategy

- **Algorithm**: SHA-256 (secure, collision-resistant)
- **Input**: Complete file bytes (via `Files.readAllBytes()`)
- **Output**: Hex-encoded hash string (64 chars)
- **Lookup**: O(1) in ConcurrentHashMap

**Why SHA-256?**
- Deterministic (same file → same hash)
- Collision-resistant (different content → different hash)
- Fast enough (~1ms for 50KB file)
- Standard (MessageDigest available)

### RecoveryProgressListener

```java
public interface RecoveryProgressListener {
    void onRecoveryStart(int totalFiles, int threadCount);
    void onFileStart(Path file, int fileNumber, int totalFiles);
    void onStringDecryptionComplete(Path file, int stringsRecovered);
    void onNameRecoveryComplete(Path file, int namesRecovered);
    void onDeobfuscationComplete(Path file, int variablesRecovered);
    void onClassRecoveryComplete(Path file, int classesRecovered);
    void onCompilationComplete(Path file, int compilationScore, boolean success);
    void onFileComplete(Path file, int fileNumber, int totalFiles, RecoveryResult);
    void onRecoveryComplete(int totalFiles, int filesRecovered, double recoveryRate);
    void onError(Path file, String errorMessage);
    
    // Nested result object
    record RecoveryResult(
        int compilationScore,
        boolean wasRecovered,
        boolean compiles,
        long processingTimeMs
    ) { }
}
```

**Thread Safety**: All callbacks called from executor threads. Listeners must handle threading.

## Usage Examples

### Example 1: CLI Progress Bar

```java
class CLIProgressListener extends RecoveryProgressListener.RecoveryProgressAdapter {
    private int totalFiles;
    
    @Override
    public void onRecoveryStart(int totalFiles, int threadCount) {
        this.totalFiles = totalFiles;
        System.out.println("Starting recovery with " + threadCount + " threads");
    }
    
    @Override
    public void onFileComplete(Path file, int fileNumber, int totalFiles,
                               RecoveryResult result) {
        int percentage = (fileNumber * 100) / totalFiles;
        System.out.printf("\r[%-50s] %3d%% %s",
            repeatChar('=', percentage / 2),
            percentage,
            file.getFileName());
    }
    
    @Override
    public void onRecoveryComplete(int totalFiles, int filesRecovered, 
                                   double recoveryRate) {
        System.out.printf("%nRecovery complete: %.1f%% (%d/%d)%n",
            recoveryRate, filesRecovered, totalFiles);
    }
}

ParallelRecoveryPipeline pipeline = new ParallelRecoveryPipeline(8);
pipeline.addProgressListener(new CLIProgressListener());
pipeline.recover(sourcesDir, resourcesDir);
```

### Example 3: Detailed Logging

```java
class DetailedLogger extends RecoveryProgressListener.RecoveryProgressAdapter {
    @Override
    public void onFileStart(Path file, int fileNumber, int totalFiles) {
        System.out.printf("[%3d%%] Processing %s...%n",
            (fileNumber * 100) / totalFiles,
            file.getFileName());
    }
    
    @Override
    public void onStringDecryptionComplete(Path file, int stringsRecovered) {
        if (stringsRecovered > 0) {
            System.out.printf("  ✓ Decrypted %d strings%n", stringsRecovered);
        }
    }
    
    @Override
    public void onNameRecoveryComplete(Path file, int namesRecovered) {
        if (namesRecovered > 0) {
            System.out.printf("  ✓ Recovered %d names%n", namesRecovered);
        }
    }
    
    @Override
    public void onCompilationComplete(Path file, int compilationScore, 
                                      boolean success) {
        System.out.printf("  ✓ Compilation: %s (score: %d)%n",
            success ? "✓" : "✗", compilationScore);
    }
    
    @Override
    public void onFileComplete(Path file, int fileNumber, int totalFiles,
                               RecoveryResult result) {
        System.out.printf("  → Completed in %dms%n%n", result.processingTimeMs());
    }
    
    @Override
    public void onError(Path file, String errorMessage) {
        System.err.printf("✗ Error in %s: %s%n", file.getFileName(), errorMessage);
    }
}
```

## Testing

### Test Compilation Cache

```java
@Test
void testCompilationCache() {
    CompilationCache cache = new CompilationCache(true);
    Path javaFile = Paths.get("Test.java");
    
    // First call - cache miss
    assertNull(cache.get(javaFile));
    
    // Add to cache
    CompilationResult result = new CompilationResult(true, new ArrayList<>(), 100);
    cache.put(javaFile, result);
    
    // Second call - cache hit
    assertNotNull(cache.get(javaFile));
    assertEquals(100, cache.get(javaFile).score());
}
```
